# 功能测试

## 电机测试
PWM控制速度。
通过按键3实现点动，按键3按下时电机启动，松开停止，再次按下改变方向（前进/后退）。

测试标准：不会卡死。

## 屏幕测试
SPI通信协议硬件实现。
通过按键3切换颜色，实现全屏填充三原色（红绿蓝）、白色、黑色共5种。

测试标准：无花屏、无闪屏。

触摸屏 坐标显示
I2C驱动，GPIO_TP_INT外部中断下降沿触发
从机地址    0x15
寄存器地址  0x02 --> 触摸点数
           0x03 --> x pos H x坐标高位
           0x04 --> x pos L x坐标低位
           0x05 --> y pos H y坐标高位
           0x06 --> y pos L y坐标低位


## 音频测试
I2S + DMA双缓冲。
方案一：播放一段音频，hello.wav转换成audio_data.h数组形式，去掉WavHeader，仅保留PCM数据。
音频采样率44100Hz，量化位数16bit，单声道。

方案二：播放单频率三角波，节省内存。

测试标准：无断音。

## 传感器测试
ADC + DMA + UART。
ADC值范围0~4095，同时根据ADC值计算并显示电压与压力。
通过按键3调零，按键2控制传感器的启动与停止，启动时开启DMA传输，每1000ms串口发送一次数据。

## 其他
WS2812B RGB灯珠*4 指示功能
PWM + DMA。

按键1模式切换，选中模块是对应模块RGB灯亮绿灯。
按键2控制开始与停止，开始时对应模块灯珠亮蓝灯，停止时恢复绿灯状态。
