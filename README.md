# 功能测试

## 电机测试
PWM控制速度。
通过按键3实现点动，按键3按下时电机启动，松开停止，再次按下改变方向（前进/后退）。

测试标准：不会卡死。

## 屏幕测试
SPI通信协议硬件实现。
通过按键2切换颜色，实现全屏填充三原色（红绿蓝）、白色、黑色共5种。

测试标准：无花屏、无闪屏。

## 音频测试
I2S + DMA双缓冲。
方案一：播放一段音频，hello.wav转换成audio_data.h数组形式，去掉WavHeader，仅保留PCM数据。
音频采样率44100Hz，量化位数16bit，单声道。

方案二：播放单频率正弦波，节省内存。

测试标准：无断音。

## 传感器测试
ADC + DMA + UART。
每500ms发送一次数据，范围0~4095。

## 其他
WS2812B RGB灯珠*4 指示功能
PWM + DMA。

按键1模式切换。


# 性能测试

（抽检）
电机循环测试：正转3s，停止1s，反转3s，停止1s。循环1000次/3000次。

LCD刷新测试：每秒切换一次颜色，连续运行24小时。

音频：循环播放音频文件连续x小时；启停测试。

传感器：连续采样x小时。
